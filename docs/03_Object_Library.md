# Object Library

## Amaç

Ayrım üretebilen başlangıç objelerini toplamak.

## Aday obje aileleri

- atasözleri
- deyimler
- yerel kelimeler ve kalıplar
- İngilizce ve diğer dillerde garip kalıplar
- herkesçe bilinen kişiler
- kurgusal karakterler
- kısa hikâyeler
- mesajlaşmalar
- ses ve podcast anlatımları
- doğa olayları
- formüller ve mekanizmalar
- hisler
- görseller
- iki obje arasında çarpıştırmalar

## İlk prototip adayı

`Üzüm üzüme baka baka kararır` × `Bir çocuğun yeni bir kelime öğrenmesi`

Açılabilecek ayrımlar:

- öğrenme / taklit
- benzeşme / seçim
- uyum / kendinden vazgeçme
- bağ kurma / kabul görme
- çevresel etki / kişisel irade
